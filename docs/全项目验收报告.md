## 四、用户全流程链路验收

按真实使用顺序串联，每一步均通过接口级验证：

1. **配置检查**：读取/写入系统配置，高阶模式开关可持久化（A3、A4）。
2. **内核就绪**：浏览器已安装、速度档位与 UA 池可用（B1~B3）。
3. **页面预览与选元素**：渲染目标页返回完整 HTML，含 `<base>` 标签，非 http 协议被拦截（C1~C4）。
4. **单页试采**：2 字段 × 3 条正确提取，并识别到"下一页"（B4~B7）。
5. **合规预检**：允许路径放行、禁止路径拦截，提示命中规则（E2~E4）。
6. **建任务与运行**：保存 → 启动 → 暂停（断点保留）→ 继续（无重复页、无重复行）→ 完成 12 条（F1~F10）。
7. **终止场景**：运行中终止，状态与断点正确，且可删除（F11~F14）。
8. **模板复用**：保存模板 → 列表 → 导出（含字段规则）→ 导入为新任务 → 删除（G1~G7）。
9. **清洗**：字段级剔除空值 + 价格符号替换，12 行 → 11 行（H1~H6）。
10. **导出**：清洗后 CSV 11 行且含 UTF-8 BOM；未清洗对照 12 行；JSON 可解析 11 条；XLSX 非空；非法格式被拦截（I1~I8）。
11. **高阶能力**：打码方案密钥可配置/保留/清除且不回传明文；自定义 UA 与请求头在真实请求中生效；方案可绑定与解绑（J1~J15）。
12. **合规兜底**：robots 禁止时启动被拦截（1003），关闭校验后放行并采完；开启限速后页间最小间隔达标（K1~K9）。

## 六、验收中发现并修复的问题

### 6.1 真实缺陷（已修复并回归）

| 编号 | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| P1 | 限速配置 600ms 时，实测页间最小间隔仅 439ms | 限速调用点在"页面请求完成之后"，旧实现按上一次调用时间戳抵扣间隔：页面处理耗时被算入间隔；且上一任务留下的时间戳会让新一轮首个页面直接跳过等待 | 改为每次调用固定等待一个配置间隔，并按 host 加锁串行，保证"请求到请求"的间隔恒不小于配置值。`RiskControlService#throttle` |
| P2 | 暂停后立即继续，续爬结果出现重复页面数据（21 条而非 12 条） | `pause()` 会先乐观地把状态置为 PAUSED，用户立即 `resume()` 时清除了控制指令；旧运行因此未感知暂停继续爬取并落库，新运行又从同一断点开始，二者重复写入 | 在页间继续判断与落库入口两处校验运行令牌：令牌失效（已被新运行取代）时旧运行立即停止落库与翻页，数据由新运行独占。`TaskExecutionService#execute / #savePage` |

修复后端到端重跑结果：**93 通过 / 0 失败**，F8=12、F9=4、K9 间隔达标。

### 6.2 验收脚本自身问题（非产品缺陷，已修正）

| 编号 | 问题 | 处理 |
| --- | --- | --- |
| T1 | 打码密钥断言检查了请求体，但密钥实际注入在请求头 | 改为校验 `X-Token` 请求头 |
| T2 | 打码方案编辑时只传了部分字段，触发"参数模板不能为空" | 补齐完整配置字段后重测 |
| T3 | 清理阶段对已删除任务再次删除，返回 1004 | 验收口径调整为"1004 视为已清理" |
| T4 | 清洗用例原设计为跨页重复行去重，但采集层已按整行哈希去重，重复行不会入库 | 改用"空标题行 + 字段级 REMOVE_EMPTY"验证行数减少，语义更贴合实际使用 |

## 八、安全约束核对

| 强制约束 | 落实情况 | 验收证据 |
| --- | --- | --- |
| Playwright 页面沙箱隔离 | 每次采集使用独立浏览器上下文，Cookie/缓存不跨任务复用 | B 组采集均通过独立会话完成 |

## 九、启动与复验步骤

1. 启动 MySQL（库 `free_collector` 已初始化）。
2. 启动 Redis（`127.0.0.1:6379`）。
3. 启动后端：

   ```powershell
   java -jar "c:\Users\29981\Desktop\多功能爬虫\server\target\free-collector-server.jar"
   ```

   日志出现 `Tomcat started on port 17893` 即就绪。

4. 启动桌面端：双击根目录 `run-dev.bat`（或 `npm run tauri dev`）。

## 十、已知限制

1. **内核多探测一页**：达到 `maxPages` 后会额外发起一次"下一页"探测请求（不落库），会多占用目标站点一次访问。
2. **robots 校验仅覆盖任务起始 URL**：翻页子路径不逐页校验，避免拖慢采集。
3. **限速为站点级串行**：同一站点多任务会排队；不同站点互不影响。
4. **预览不保留登录态**：预览为一次性会话，需要登录的站点需依赖任务级 Cookie 配置。
5. **随机 class 选择器不稳定**：目标站重构后需重新选取元素（产品本身支持可视化重选）。
6. **XLSX 导出上限 10 万行**：超过需分批导出（流式写出，低内存）。
7. **单机形态限制**：V1 无分布式、无账号体系、无云端同步，符合既定产品边界。
8. **打码不内置识别模型**：仅做 HTTP 透传，识别能力取决于用户配置的第三方平台。
9. **GUI 未做人工点击验收**：本次为接口级全流程自动化验收 + 前端构建通过（`vite build` 成功）；界面交互建议在试用阶段由人工走查一轮。
